# ﻿Guess The Price - Python Game

Este proyecto es un juego interactivo de escritorio desarrollado íntegramente en Python, inspirado en formatos televisivos de entretenimiento. El sistema pone a prueba el conocimiento del usuario sobre el valor de mercado de distintos productos. A nivel técnico, el proyecto destaca por la modularización del código, el manejo de lectura/escritura de archivos .txt para la persistencia de puntajes y catálogos, y la integración fluida de recursos multimedia (imágenes y efectos de sonido) para mejorar la experiencia de usuario.
